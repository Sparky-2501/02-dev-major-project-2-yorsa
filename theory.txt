CORS:
    -Cross-Origin Resource Sharing, is a security feature implemented by web browsers to control how web applications can request resources from different origins
    -prevent malicious websites from making unauthorized requests to another site on behalf of the user.

    how it works?
        -web appllication make a request to the Resource.
        -browser check if the target server allow the request.
        -this is done by server sending specific HTTP headers in response.
        -headers dictate what types of requests are allowed from different origins.
    
    imp headers:
        -Access-Control-Allow-Origin -specifies the Origin
        -Access-Control-Allow-Methods -list HTTP methods
        -Access-Control-Allow-Headers -specifies HTTP Headers
        -Access-Control-Allow-Credentials -indicate whether the request can include the user credentials
        -Access-Control-Expose-Headers -indicate which headers can be exposed to the browser

WebRTC:

    we have our camera our stream on my own browser now how does person x sees this stream on his browser ?
    MediaStream exists only inside your browser memory.person x's browser has absolutely no access to it
    So we need something that says "Take my MediaStream and send it to Rahul." That is WebRTC.

So WebRTC's job is :Transport MediaStreams between browsers.
